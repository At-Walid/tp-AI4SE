# IA pour le GL — Tests : dépôt du TP

Travaux pratiques de 90 minutes (Master 2 Génie Logiciel) : génération de tests assistée par
IA pour des systèmes IA critiques.

- **Étudiants** : lisez [`tp/README.md`](tp/README.md) (démarrage en moins de 5 minutes).
- **Enseignants** : lisez [`instructor/README.md`](instructor/README.md) (absent de la version étudiante).

Environnement : une image Docker unique (`make build`), utilisable aussi dans GitHub Codespaces
ou VS Code Dev Containers (`.devcontainer/`). Python 3.11, amd64 et arm64, sans GPU, hors ligne
une fois l'image construite.
